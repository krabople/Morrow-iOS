# Listello Privacy Policy

Last updated: 6 September 2026

Listello does not collect, transmit, sell or share personal data. Tasks, projects, preferences and archive data are stored locally on the user's device.

Calendar access is optional. When a user enables calendar features, Listello reads calendar events only to show them alongside the schedule and writes events only when the user explicitly requests an export. Listello does not send calendar data to the developer or any third party.

Reminders access is optional. When a user chooses to import, Listello reads the selected Apple Reminders lists and copies incomplete reminders into local projects or lists. It does not change the original reminders or send their data anywhere.

Notification access is optional. Notifications are created locally on the device for tasks and days selected by the user.

Listello does not contain advertising, analytics, tracking technology, accounts or third-party software development kits.

For privacy questions, please use the [Listello support page](SUPPORT.md).
